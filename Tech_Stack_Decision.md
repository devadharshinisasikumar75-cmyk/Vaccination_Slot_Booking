# Technology Stack Decision

## Frontend
- React.js

Reason:
React.js is used to build a fast, responsive, and interactive user interface using reusable components.

## Backend
- Java
- Spring Boot

Reason:
Spring Boot is used to develop secure and scalable REST APIs with minimal configuration.

## Database
- MySQL

Reason:
MySQL stores user information, vaccination details, appointment records, and other application data.

## Build Tool
- Maven

Reason:
Maven manages project dependencies and automates the build process.

## Version Control
- Git

Reason:
Git is used to track source code changes during development.

## Repository Hosting
- GitHub

Reason:
GitHub is used to store the project repository and collaborate with team members.

## IDE
- Visual Studio Code

Reason:
VS Code provides an efficient development environment for React, Java, and Spring Boot.

## API Testing
- Postman

Reason:
Postman is used to test and verify REST APIs.
